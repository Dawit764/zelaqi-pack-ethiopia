# Zelaqi Pack Ethiopia (ዘላቂ ፓክ ኢትዮጵያ)

An interactive business plan website I designed and developed for my university Business Planning course. Instead of creating a traditional PowerPoint presentation, I built a modern web application that presents our startup idea through an engaging and interactive experience.

The project showcases **Zelaqi Pack Ethiopia**, a proposed eco packaging startup focused on manufacturing affordable, durable paper bags as a sustainable alternative to single use plastic bags. It was submitted on **May 7, 2026**, under the supervision of **Nitsuh K.**

## About the Project

The name **Zelaqi (ዘላቂ)** means *sustainable* or *long lasting* in Amharic. It reflects our vision of providing environmentally friendly packaging solutions that help businesses transition away from single use plastic bags following Ethiopia's **Proclamation No. 1383/2025**.

The proposed business is planned as a partnership with an initial investment of **500,000 ETB**. The manufacturing workshop will be located in **Addis Ketema, Addis Ababa**, near Merkato, one of Ethiopia's largest wholesale markets. Our goal is to supply high quality paper bags to retailers and wholesalers at an affordable starting price of **10 ETB per bag**.

Although the business plan was developed as a team project, I independently designed and built this website to transform our report into a professional digital presentation.

## Getting Started

### Clone the Repository

```bash
git clone <repository-url>
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```
